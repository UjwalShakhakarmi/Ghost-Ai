# ArchAI – Real-Time Collaborative AI System Design Platform

ArchAI is a real-time collaborative system design workspace. Users describe a system in plain English, an AI agent maps that architecture onto a shared canvas, collaborators refine the graph together, and the platform generates a persistent technical specification.

## Tech Stack

- **Frontend / Framework:** Next.js, React, TypeScript, Tailwind CSS
- **Canvas & Collaboration:** React Flow, Liveblocks, WebSockets
- **AI & Workflows:** LLM Integration, Durable Background Tasks
- **Storage & State:** Canvas State Snapshots, Persistent Markdown Export
